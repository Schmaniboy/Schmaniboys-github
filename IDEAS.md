# IDEAS

Sammlung von Ideen und moeglichen Funktionen. Eine Idee hier bedeutet NICHT, dass sie umgesetzt werden muss.

## Format

- **Idee:** Kurzbeschreibung
- **Kategorie:** Bereich
- **Prioritaet:** Hoch / Mittel / Niedrig / Unklar
- **Status:** Neu / Besprochen / In Planung / Verworfen

---

## Fahrzeugidentifikation

### I-001: VIN/FIN Decoder
- **Idee:** Fahrgestellnummer eingeben und Fahrzeug automatisch identifizieren
- **Kategorie:** Identifikation
- **Prioritaet:** Hoch
- **Status:** Besprochen

### I-002: HSN/TSN Lookup
- **Idee:** Schluesselnummern aus dem Fahrzeugschein eingeben fuer Fahrzeugidentifikation
- **Kategorie:** Identifikation
- **Prioritaet:** Hoch
- **Status:** Besprochen

### I-003: Manuelle Fahrzeugauswahl
- **Idee:** Schritt fuer Schritt: Hersteller → Modell → Generation → Baujahr → Motor
- **Kategorie:** Identifikation
- **Prioritaet:** Hoch
- **Status:** Besprochen
